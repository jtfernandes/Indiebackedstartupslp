# Mockups

Static HTML wireframes for IndieBacked Startups v2. One file per section
mockup, low-fi pencil/sketch style — pencil.dev-flavoured. Open any `.html`
file directly in a browser. No build step.

Convention: `<section>-<n>.html` where `n` increments per design exploration
of the same section. Annotations and copy provenance live inside the file.

| File | Section | Notes |
|---|---|---|
| `hero-01.html` | §1 Hero | First pass. Headline left, full-width status rail below. EN + PT variants stacked at bottom. |

Copy is locked from `V2_COPY_DECK.md` — these mockups are exploring **shape**,
not wording. Production styling stays dark (`#110522`); the cream paper is
only the wireframe surface.
